# Yellow Aura

**Interactive music visualizer with aura-themed energy visuals.**

Live demo: [https://silver-crisp-royal-breeze.grok.me/](https://silver-crisp-royal-breeze.grok.me/)

Local recreation: open `index.html` in any modern browser (mic requires HTTPS or localhost).

Created with Grok App Builder. Built for Mysterious Enterprise LLC / CrypticStore.Shop / MC Myster?ous.

## What it does

Yellow Aura is a real-time audio visualizer that turns microphone input, uploaded tracks, or a built-in demo groove into glowing aura visualizations.

### Features
- **Input options**: Use microphone, drop/upload an audio file, or play the demo groove
- **Visualizations**: Bars, Radial, Halo
- **Color themes**: Aura, Ivory, Flare, Noir
- **Sensitivity control**: Adjust how the visuals react to the audio
- **Fullscreen support**
- Minimal, dark, premium interface with wordmark and live status ("Waiting for a signal")

### Description (from meta)
> Yellow Aura is a music visualizer for your microphone or a track.

## Local version (`index.html`)

Self-contained single-file recreation using Web Audio API + Canvas. Supports:
- Mic input (needs user permission + secure context)
- File upload (looped playback)
- Demo groove (simple oscillator)
- All three visualizations and four themes
- Sensitivity + fullscreen

Open it directly or serve it locally for full mic support.
